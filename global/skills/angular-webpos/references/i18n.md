# Traducciones (ngx-translate)

Todo texto visible al usuario va traducido en **español e inglés**. Las traducciones son objetos TypeScript,
no JSON, y se cargan una sola vez en `app.component.ts` (`translationService.loadTranslations(enLang, esLang)`).
No cargues traducciones en cada componente.

## Archivos

```
src/app/_config/lang/
├── es.ts / en.ts                         ← raíz: importa cada feature y la cuelga de una clave
├── common/common.{es,en}.ts              ← COMMONS: botones, mensajes, confirmaciones, tabla…
└── <feature>/<entidad>/<entidad>.{es,en}.ts
```

Archivo de feature (`admin/carrier/carrier.es.ts`):

```typescript
export const carrier = {
  TITLE: 'Transportistas',
  BTN: { ADD: 'Agregar Transportista' },
  TABLE: { NAME: 'Nombre', EDIT_TOOLTIP: 'Editar transportista' },
  FORM: { NAME_LABEL: 'Nombre / Razón Social', NAME_PLACEHOLDER: 'Nombre del transportista' },
  VALIDATION: { NAME_REQUIRED: 'El nombre es obligatorio' },
  MESSAGES: { DELETE_SUCCESS: 'Transportista eliminado' },
  CONFIRM: { DELETE: '¿Eliminar a {{name}}?' },
};
```

- El `.en.ts` exporta **la misma constante** (`export const carrier`) con **exactamente las mismas claves**.
- Registro en `es.ts` **y** `en.ts`: `import { carrier } from './admin/carrier/carrier.es';` y dentro de
  `locale.data`: `CARRIER: carrier,`. La clave raíz en MAYÚSCULAS es el prefijo que usan las plantillas.
- Si añades textos a una pantalla existente, edita su archivo de feature; no crees otro.

## Convención de claves

`FEATURE.SECCION.CLAVE` con secciones habituales: `TITLE`, `TITLE_ADD`, `TITLE_EDIT`, `BTN`, `TABLE`, `FORM`,
`VALIDATION`, `MESSAGES`, `CONFIRM`.

Antes de crear una clave, busca en `COMMONS` (`common.es.ts`): ya existen `BUTTONS` (SAVE, CANCEL, YES_DELETE…),
`MESSAGES` (LOADING_DATA, SAVING_DATA, OPERATION_ERROR…), `CONFIRM` (ARE_YOU_SURE…), `TABLE` (ACTIONS, EDIT, DELETE…),
`TITLES`, `VALIDATION`, `PANE_DESC` (descripción bajo el título de cada pantalla), `COUNTERPART_ROLES`.

## Uso

```html
<h1 class="pane__title">{{ 'CARRIER.TITLE' | translate }}</h1>
<input [placeholder]="'CARRIER.FORM.NAME_PLACEHOLDER' | translate">
<span>{{ 'CARRIER.FORM.SHARED_IDENTITY_HINT' | translate: { roles: sharedRoles() } }}</span>
```

```typescript
private translate = inject(TranslateService);
this.toastr.success(this.translate.instant('CARRIER.MESSAGES.DELETE_SUCCESS'));
this.translate.instant('CARRIER.CONFIRM.DELETE', { name });
```

- Importa `TranslateModule` en el `imports` del componente.
- `instant()` para toastr, SweetAlert y configuración de columnas; no uses `get().subscribe()` salvo que necesites reaccionar al cambio de idioma.
- Interpolación con `{{param}}` dentro del texto.

## Reglas

- Nunca texto literal en español/inglés en plantillas, toastr o Swal.
- Toda clave nueva existe en `.es.ts` y `.en.ts` → verifícalo con `node "$HOME/.claude/skills/wp-frontend/scripts/check-i18n.js"` (desde la raíz del repo).
- Deuda conocida: algunas pantallas tienen etiquetas de exportación (`exportColumns`) en español literal. No copies ese patrón.
